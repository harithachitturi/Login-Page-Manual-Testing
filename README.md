# Login Page Manual Testing Project

## 1. Project Overview
This project focuses on manual testing of a website login page.

## 2. Project Objective
To verify that the login functionality works correctly with valid and invalid user credentials.

## 3. Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Validation Testing

## 4. Test Scenarios
1. Verify login with valid username and password.
2. Verify login with invalid username.
3. Verify login with invalid password.
4. Verify login with empty username.
5. Verify login with empty password.
6. Verify login with both fields empty.
7. Verify password masking.
8. Verify error messages.

## 5. Skills Used
- Manual Testing
- Test Case Design
- Bug Reporting
- Functional Testing

- GitHub
- Microsoft Excel
